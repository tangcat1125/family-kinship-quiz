# 家族大搜查：親人稱謂大解密 (Family Kinship Quiz)

純前端離線情境推理遊戲，專為國小社會科「親人的稱呼／親人的往來」單元量身打造。

---

## 🚀 真正零伺服器・滑鼠直接雙擊啟動

本遊戲採用 **100% 純原生單一 HTML 架構**：
- ❌ **不需要本機伺服器**（無須 `http://localhost`、無須 Node.js、無須 Python http.server）
- ❌ **無 CORS 跨域限制**（未使用 `<script type="module">`，無外部 fetch 依賴）
- ❌ **不需要網路連線**（完全離線執行）

### 💡 啟動方式：
在檔案總管中，直接對著 **`index.html`** 點兩下滑鼠左鍵（雙擊），就能立刻在 Chrome、Edge、Firefox 等任何瀏覽器中秒開遊玩！

## ⌨️ 快捷鍵支援

* **`1`、`2`、`3`、`4`**：快速選取第 1 ~ 4 張稱謂卡牌。
* **`Enter`**：確認送出答案。
* **`Space`（空白鍵）**：重新朗讀 NPC 的自我介紹。
* **`H`**：取得下一條線索提示。
